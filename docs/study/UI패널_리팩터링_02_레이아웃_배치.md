# UI 패널 리팩터링 2편 — 스케치대로 실제 배치

1편에서 만든 사이드 패널(300x800 논리 버퍼)에, 사용자가 그려준 스케치(LaunchWorld.png/MainWorld.png)
순서대로 기존 위젯들을 재배치했다.

## LaunchWorld (`Widget_Launch::Init()`)
- "First Orbit" 타이틀 텍스트 신규 추가 (상단, 폰트 28)
- 상태 텍스트(Awaiting Launch / Altitude / HorizontalVelocity): 폰트 40/30 → 20/16으로 축소.
  패널 폭이 300px라 예전 폰트 크기 그대로 두면 "HorizontalVelocity : 0" 한 줄이 패널 폭을
  넘어갔을 것.
- 점수/콤보: 아직 시스템 자체가 미확정(브레인스토밍 중)이라, **값 연결 없이 텍스트 자리만**
  "점수 : 0" / "콤보 : 0"으로 잡아둠 (TODO 주석 남김)
- 스케치의 보라색 버튼 3개(파워업/보너스 후보): 실제 기획이 뭘지 안 정해진 상태라 기능 없는
  빈 버튼을 만드는 대신 **자리와 이유를 TODO 주석으로만 남기고 실제 버튼은 안 만듦** — 나중에
  기획 정해지면 그때 추가
- Fire 버튼: 위치 그대로 EAnchor::Center 유지 (패널 안에서 중앙)
- 연료바: 위치 그대로 LeftBottom 유지

## MainWorld (`Widget_Main::Init()`)
- "First Orbit" 타이틀 텍스트 신규 추가
- 상태 텍스트 5줄(속도/근지점/원지점/상태/중력원): 이미 필요한 것만 추리는 중이었어서(그대로 둠),
  타이틀과 안 겹치게 시작 y좌표만 20 → 60으로 내림, 폰트 20 → 18
- 헤딩 인디케이터: 기존엔 우하단(RightBottom)이라 연료바 옆 Refuel 버튼과 겹쳤음(패널 폭 300에
  연료바 150 + Refuel 버튼 60 + 헤딩 인디케이터 60을 한 줄에 다 못 넣음) → 우상단(RightTop)으로
  이동, 크기도 60→50으로 살짝 축소
- 행성 버튼(`_planetButtons`, 지금은 예전 자리에 임시로만 재배치): RightTop 겹침 자리 피해서
  LeftTop, 텍스트 블록 아래(y=190~)로 이동. **3단계(통합 액터 버튼)에서 완전히 새로 설계할
  영역이라 지금은 임시 배치**

## 확인 (Release 실행, 실제 스크린샷)
- LaunchWorld: 타이틀 → 상태텍스트 → 점수/콤보 → Fire 버튼 → 연료바, 스케치와 거의 동일하게 나옴
- MainWorld: 타이틀+헤딩 인디케이터(우상단), 연료바+Refuel(좌하단, 겹침 없음) 확인.
  단, 상태 텍스트 5줄이 화면에 안 보였음 — **원인 조사해보니 `MainWorld::UpdateUIData()` 함수
  자체는 있는데 아무 데서도 호출을 안 하고 있었음(기존부터 있던 버그, 이번 작업과 무관)**.
  이번 리팩터링 범위 밖이라 손 안 댔음 — 필요하면 별도로 `Update()`에 `UpdateUIData();`
  호출 추가하면 됨.
