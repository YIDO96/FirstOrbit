# UI 패널 리팩터링 5편 — UIButton 비활성 상태 + 통합 액터 버튼

## 1. UIButton "비활성(흐림)" 상태 추가

기존엔 `SetActive(bool)`(아예 숨김) 하나뿐이라, "보이긴 하는데 지금은 누를 수 없는" 상태를
표현할 방법이 없었다. 우주선이 픽된 상태에서 "지금 못 가는 행성" 버튼을 표시하려면 이게 필요.

- `UIButton`에 `_isInteractable` 추가, `SetInteractable(bool)` / `IsInteractable()`
- `Update()`: 비활성이면 호버 확대/클릭 반응 전부 스킵 (원래 크기 고정, 텍스트만 갱신)
- `Render()`: 비활성이면 버튼을 그린 뒤 위에 반투명 검정을 `AlphaBlend`로 한 번 더 덮어서 흐리게
  보이게 함. `Glow.cpp`가 쓰던 `AC_SRC_ALPHA`(픽셀별 알파) 방식과 달리, 여긴 1x1 불투명 검정
  비트맵 하나를 `SourceConstantAlpha=150`으로 균일하게 얹는 훨씬 단순한 방식 사용.

## 2. 통합 액터 버튼 (우주선 + 태양계 + 블랙홀, 11개)

기존엔 "행성 선택 버튼"(전이용, `ShowPlanetButtions`)과 "액터 포커스"(ImGui 하이어라키
더블클릭으로 카메라만 이동)가 서로 다른 두 시스템이었다. ImGui가 Release에서 사라지니
포커스 기능도 자체 UI로 옮겨야 했고, 겸사겸사 사용자 요청대로 둘을 버튼 하나로 합쳤다.

### Widget_Main
- `_planetButtons`(9개, 태양+8행성) → `_actorButtons`(11개: 우주선+태양계9+블랙홀) 로 교체
- `ShowActorButtons(vector<AActor*>)`: 액터 목록 받아서 버튼 11개를 한 번만 생성 (텍스트=액터
  이름, 클릭 시 `_onActorSelected(해당 액터)` 호출). **주의**: 이 함수는 `Init()`이 아니라
  `MainWorld::Enter()`에서 액터들이 다 스폰된 뒤 호출되므로, `SetActiveUISpace(true/false)`
  토글을 이 함수 안에서 다시 해줘야 함 (Init() 안에서 한 번 했다고 끝난 게 아님).
- `UpdateActorButtonStates(shipPicked, reachable)`: 매 프레임이 아니라 **선택 상태가 바뀌는
  순간에만** 호출(성능 때문 — 아래 참고). 우주선 버튼 자신과, 우주선이 안 픽힌 상태에서는
  전부 활성. 우주선이 픽힌 상태에서는 행성만 `reachable` 포함 여부로 활성/비활성, 행성이
  아닌 것(블랙홀 등)은 항상 활성.

### MainWorld — 클릭 경로를 하나로 통합
뷰포트 클릭(`PickActor`)과 버튼 클릭이 전부 같은 `MainWorld::SelectActor(AActor*)`를 타도록
정리:

```cpp
void MainWorld::SelectActor(AActor* actor)
{
    if (actor == _ship)
    {
        // 우주선 픽 → 목적지 선택 모드 진입
        _selected = _ship;
        _widget->UpdateActorButtonStates(true, GetReachablePlanets());
        return;
    }
    if (_selected == _ship)
    {
        if (APlanet* planet = dynamic_cast<APlanet*>(actor))
        {
            StartTransfer(planet);   // 기존 인라인 코드를 함수로 분리
            return;
        }
    }
    // 그 외엔 포커스만
    _selected = actor;
    _widget->UpdateActorButtonStates(false, {});
}
```

`StartTransfer()`는 기존에 버튼 콜백 안에 인라인으로 있던 전이 계산 코드를 그대로 옮긴
것뿐이고, 끝에 `_selected = nullptr; UpdateActorButtonStates(false, {});`를 추가해서 전이를
걸면 목적지 선택 모드가 자동으로 풀리게 했다.

### 성능 관련 주의
`GetReachablePlanets()`는 행성마다 `FindBestTransfer`(람베르트 100회 이상 풀이)를 돌리는
무거운 함수다. **매 프레임 호출하면 안 됨.** 그래서 `UpdateActorButtonStates`는 매 프레임이
아니라 "우주선을 픽하는 그 순간"에만 호출하도록 했다 — 이건 원래 있던
`ShowPlanetButtions(GetReachablePlanets())`도 클릭 시 1회만 호출하던 것과 같은 패턴.

## 검증 (Release 실행)
- 처음엔 11개 버튼(SpaceShip/Sun/Mercury~Neptune/BlackHole) 전부 밝게 표시됨 확인
- SpaceShip 클릭 → Sun만 흐려지고(람베르트가 태양 중심으로는 항상 실패하므로 자연스럽게
  도달 불가 판정) 나머지는 밝게 유지되는 것 확인
- Earth 클릭 → 실제로 전이가 걸리고(카메라가 줌아웃되며 궤도 변화), 동시에 Sun이 다시
  밝아지며 목적지 선택 모드가 정상적으로 풀리는 것까지 확인
