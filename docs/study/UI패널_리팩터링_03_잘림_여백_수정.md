# UI 패널 리팩터링 3편 — 오른쪽 여백(잘려 보이던 부분) 수정

## 증상
패널이 창 오른쪽 끝까지 안 채워지고, 패널 뒤쪽에 허연 여백이 남아있었음. 그 여백 자리에
작업표시줄(아이콘/알림 텍스트)이 겹쳐 보여서 마치 UI가 잘린 것처럼 보였음.

## 원인
`UpdateGameViewport()`에서 패널 크기를 계산할 때, 게임 화면과 똑같이 **비율 유지**
(`min(가로스케일, 세로스케일)`) 방식을 그대로 갖다 썼다. 게임 화면은 액터 좌표계라 비율이
깨지면 안 되지만, 패널은 그냥 텍스트/버튼 나열이라 비율을 지킬 이유가 없었음. 패널의 논리
해상도(300x800, 세로로 긴 비율)가 실제 남는 공간(가로로 더 넓은 비율)보다 홀쭉해서, 세로
기준으로 스케일이 정해지고 가로는 남는 공간을 다 못 채운 채 여백이 생겼다.

## 해결
패널은 비율 유지 없이 **남는 공간을 가로/세로 각각 꽉 채우도록** 변경.

```cpp
// 이전: 비율 유지(min) → 여백 발생
float panelScale = min(panelDestW / (float)GImGuiPanelWidth, destH / (float)GWinSizeY);

// 이후: 가로/세로 따로 꽉 채움
_panelViewport = { destW, 0, destW + panelDestW, destH };
_panelRectRatio = Vector2(panelDestW / (float)GImGuiPanelWidth, panelDestH / (float)GWinSizeY);
```

가로/세로 스케일이 달라질 수 있어서(비율 유지를 포기했으니까), `GetPanelRectRatio()`의
반환 타입을 `float` → `Vector2`로 바꾸고, `UIBase::IsHoverInUI()`의 마우스 좌표 보정도
x/y를 각각 나누도록 수정.

## 수정 파일
- `Core/GameInstance.h` / `.cpp`
- `GameFramework/UIBase.cpp`

## 검증
Release 실행 후 스크린샷 확인 — 패널이 창 오른쪽 끝까지 꽉 채워짐, 여백/잘림 없음.
