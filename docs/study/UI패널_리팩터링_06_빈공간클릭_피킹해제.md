# UI 패널 리팩터링 6편 — 빈 공간 클릭 시 피킹 해제

## 요청
게임 화면(뷰포트)의 빈 공간을 클릭하면 지금 픽/선택된 상태가 풀리도록 추가.

## 이전 상태
`MainWorld::Update()`의 클릭 핸들러가 `PickActor(worldPos)`가 액터를 찾았을 때만
`SelectActor()`를 호출했고, 빈 공간을 클릭해서 `PickActor`가 `nullptr`을 반환하면
아무 일도 안 일어났다 — 즉 우주선을 픽한 채로 빈 공간을 눌러도 "목적지 선택 모드"가
계속 유지되고 버튼도 계속 흐린 상태로 남아있었음.

## 해결
`MainWorld::DeselectActor()` 추가:
```cpp
void MainWorld::DeselectActor()
{
    _selected = nullptr;
    _camera.SetFollowTarget(nullptr);
    _widget->UpdateActorButtonStates(false, {});
}
```
클릭 핸들러에서 `PickActor`가 아무것도 못 찾으면 이걸 호출하도록 `else` 분기 추가:
```cpp
if (AActor* picked = PickActor(worldPos))
    SelectActor(picked);
else
    DeselectActor();   // 빈 공간 클릭 → 픽/선택 해제
```

카메라 팔로우도 같이 풀어주는 이유: 이 프로젝트는 픽/선택과 카메라 팔로우를 항상 같이
묶어서 다뤄왔음(`SelectActor`도 선택할 때 `_camera.SetFollowTarget(actor)`를 같이 부름) —
그 짝을 맞춰서 선택 해제 시에도 팔로우를 같이 풀어줌 (`Camera::UpdateFollow`가 이미
`_followTarget == nullptr`을 안전하게 처리하고 있어서 그대로 넘겨도 됨).

## 수정 파일
- `Worlds/MainWorld.h` / `.cpp`

## 검증 (Release 실행)
SpaceShip 버튼으로 픽 → Sun 버튼 흐려짐 확인 → 게임 화면의 빈 공간(우주) 클릭 →
Sun 버튼이 다시 밝아지고, 카메라도 더 이상 우주선을 따라가지 않는 것까지 확인.
