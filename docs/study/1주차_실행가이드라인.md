# 1주차 실행 가이드라인 — 매일 열어두는 문서

> **이 문서는 "오늘 뭘 하나"만 담는다.** 개념·유도·왜는 `1주차_학습가이드.md`에 있다.
> 막히면 → 학습가이드 해당 `B-n` 절 → `참고자료.md` 5절 역인덱스.

## 0. 사용법

### 두 문서의 역할

| 문서 | 담는 것 | 언제 |
|---|---|---|
| `1주차_학습가이드.md` | 개념 · 수식 유도 · 왜 그런가 | 주차 시작 전 한 번, 막혔을 때 |
| **이 문서** | 순서 · 시그니처 · 검증 · 시간 | **매일 열어두고 체크** |

### ⏱ 막혔을 때 이탈 기준 (중요)

각 항목에 **예상 소요시간**이 붙어 있다. 이 시간을 넘기면 순서대로:

```
예상 × 1.5 초과  →  학습가이드의 해당 B-n 절을 다시 읽는다
예상 × 2   초과  →  참고자료.md 5절 역인덱스에서 자료를 찾는다
예상 × 3   초과  →  ⚠️ 실력 문제가 아니라 접근이 잘못됐다는 신호다.
                     막힌 내용을 기록하고 다음 항목으로 넘어간다.
                     (하루 뒤에 보면 대개 5분 만에 풀린다)
```

**한 곳에 갇히는 게 1주차 최대 위험이다.** 15개 TODO가 이미 빡빡하다.

> ⚠️ **아래 값은 실제로 돌려보고 정한 게 아니라 계산으로 뽑은 출발점이다.**

| 항목 | 시작값 | 근거 |

# Day 2 — Matrix3x3

> **목표:** 행렬 클래스가 완성되고 역행렬 2종이 서로 일치한다.
> **📖 시작 전 읽기:** 학습가이드 A-1, A-2, A-3 (+ 3Blue1Brown 3·4편)

### 체크리스트 — `B-2`

- [ ] **2-1. 구조체 선언 + 규약 주석** `~10분`
  ```cpp
  // pch.h — Vector2 바로 아래
  // 열벡터 규약: p' = M * p,  p = (x, y, 1)ᵀ.  m[행][열].
  struct Matrix3x3 { float m[3][3] = {}; ... };
  ```
  - ⚠️ **`m[행][열]` 규약을 주석으로 못 박아라.** 이게 흔들리면 전체가
    조용히 전치(transpose)된 채로 돌아간다

- [ ] **2-2. 정적 생성자 4종** `~30분`
  `Identity()` → `Translate(t)` → `Scale(s)` → `Rotate(rad)` **이 순서로**
  - 각각 만들자마자 `TransformPoint`가 아직 없으니 성분을 직접 눈으로 확인
  - `Rotate`는 학습가이드 A-2의 행렬을 그대로

- [ ] **2-3. `operator*`** — `0-B` `~30분`
  - `C[i][j] = Σ_k A[i][k] · B[k][j]`
  - ⚠️ **결과를 자기 자신에 누적하지 말 것.** 별도 결과 객체에 쓰고 반환
  - **즉시 검증:** `A * Identity()` 의 모든 성분이 `A`와 같은가

- [ ] **2-4. `TransformPoint` / `TransformVector`** — `0-C` `~20분`
  - Point는 `(x,y,1)`, Vector는 `(x,y,0)`
  - **즉시 검증:** `Translate((10,20))` 에 대해
    Point`(3,4)`→`(13,24)`, Vector`(3,4)`→`(3,4)`  ← **이동 무시 확인**

- [ ] **2-5. 검증 9종 통과** `~30분`
  학습가이드 `B-2`의 검증 목록 전부. 특히:
  - **8번 `T*S` vs `S*T` 는 달라야 하고, 9번 `S*R` vs `R*S` 는 같아야 한다**
  - 둘 다 같으면 곱셈이 틀렸고, 둘 다 다르면 회전/스케일을 확인

### 체크리스트 — `B-3` 역행렬

- [ ] **2-6. `Inverse()` 아핀 전용** — `0-D` `~40분`
  - `M⁻¹ = |A⁻¹, -A⁻¹t|` (학습가이드 A-5)
  - ⚠️ 이동 항을 `-t`로 두는 실수 — **`zoom=1`에서는 안 보인다**
  - ⚠️ `det ≈ 0` 처리 (`SMALL_NUMBER`가 `pch.h`에 있다) → 항등행렬 반환

- [ ] **2-7. `InverseGeneral()` 여인수 전개** — `0-D'` `~40분`
  - ⚠️ **수반행렬의 "전치"를 빼먹는 게 최고 빈출 실수**

- [ ] **2-8. 두 역행렬 대조** `~20분`
  - `V * V.Inverse()` = 항등행렬
  - `Inverse()` 와 `InverseGeneral()` 성분 일치
  - ⚠️ **`zoom = 0.01`과 `zoom = 50` 두 경우 모두.** `zoom=1`은 무의미하다

### ✅ Day 2 끝 판정
> 검증 9종 + 역행렬 대조가 전부 통과한다.
> 특히 **`zoom≠1`에서 `Inverse()`와 `InverseGeneral()`이 소수점까지 일치**한다.

# Day 3 — 뷰 행렬 + 줌 보간 📸

> **목표:** 화면에 뭔가 그려지고 휠로 줌이 된다. **1주차의 고비다.**
> **📖 시작 전 읽기:** 학습가이드 A-3(검산식), A-4, A-6

### 체크리스트 — `B-4` 뷰 행렬

- [ ] **3-1. `Camera` 필드 추가** `~15분`
  ```cpp
  float _rotation = 0.f, _targetRotation = 0.f, _manualRotation = 0.f;
  Matrix3x3 _view, _invView;
  void UpdateViewMatrix();
  ```
  - ⚠️ 기존 `WorldToScreen`이 `_width/_height`를 저장해놓고 전역 `GWinSizeX/Y`를 쓴다.
    **멤버 값으로 통일할 것** (그래야 `Init`이 의미를 가진다)

- [ ] **3-2. `UpdateViewMatrix()` — 회전 없이 먼저** — `1-A` `~30분`
  ```
  _view = T(half) · S(zoom) · T(-position)      // ← R은 아직 넣지 말 것
  _invView = _view.Inverse()
  ```
  - **검증:** `zoom=1, pos=(0,0)` 에서 `WorldToScreen((0,0))` → `(240, 400)`
  - **검증:** `(p - pos)*zoom + half` 와 일치 (여러 zoom·pos로)

- [ ] **3-3. `R(θ)` 추가** `~15분`
  ```
  _view = T(half) · S(zoom) · R(_rotation + _manualRotation) · T(-position)
  ```
  - **검증:** `zoom*Rotate(p-pos, θ) + half` 와 일치
  - ⚠️ **3-2를 통과하기 전에 회전을 켜지 말 것.** 둘 다 틀리면 원인을 못 찾는다

- [ ] **3-4. `ScreenToWorld` 왕복 검증** — `1-A'` `~20분`
  - `ScreenToWorld(WorldToScreen(p)) == p`
  - ⚠️ **`zoom = 0.01`, `rotation = 37°` 처럼 딱 안 떨어지는 값으로.**
    `zoom=2`, `rot=90°` 같은 예쁜 값은 부호 실수가 우연히 상쇄된다

- [ ] **📸 3-5. 곱셈 순서 버그 재현 + 촬영** `~20분`
  - `S`를 맨 앞으로 옮겨본다 → 화면이 좌상단으로 빨려든다
  - `R`을 `T(-position)` 앞으로 → 카메라가 멀수록 크게 휩쓸린다
  - **⭐ 스크린샷을 남길 것.** 고친 뒤엔 재현하려면 코드를 되돌려야 한다

### 체크리스트 — `B-5` 줌 보간

- [ ] **3-6. `Camera::Update` 로그 보간** — `1-B` `~40분`

## 참고 — 막혔을 때 확인 순서

**변수를 하나씩 꺼서 범위를 좁힌다.**

1. `rotation = 0` 으로 하면 되는가? → 되면 **회전** (정렬 부호, `R`의 곱셈 위치, 각도 보간)
2. `zoom = 1` 로 하면 되는가? → 되면 **줌** (역행렬 `-A⁻¹t`, 곱셈 순서)
3. `position = (0,0)` 으로 하면 되는가? → 되면 **이동**
4. 창 크기를 원래대로 하면 되는가? → 되면 **레터박스 변환 누락**
5. 행렬 성분을 직접 찍어서 학습가이드 A-3 검산식과 대조
6. 그래도 모르겠으면 `Identity()`부터 한 단계씩

> 💡 **회전 → 줌 → 이동 순으로 끄는 게 핵심.** 가장 최근에 추가한 것부터
> 의심하게 되어 원인에 빨리 닿는다.
