# UI 패널 리팩터링 1편 — 사이드 패널 렌더링 구조 신설

## 배경
Release 빌드에서는 ImGui를 완전히 꺼버리기로 했음(별도 문서 참고: ImGui Release 제외 작업).
그러면 ImGui가 쓰던 오른쪽 공간(`GImGuiPanelWidth` = 300px)이 텅 비게 되는데, 그 자리에
지금 게임 화면 안에 흩어져 있는 커스텀 UI(연료바, Refuel 버튼, 행성 선택 버튼, 헤딩 인디케이터 등)를
옮겨서 채우기로 했다.

## 문제: UI가 물리적으로 게임 버퍼에 갇혀 있었음
`GameInstance`는 게임 로직을 `GWinSizeX x GWinSizeY`(600x800) 고정 크기 비트맵(`_hdcGame`)에
그린 뒤, 창 크기에 맞춰 레터박스로 확대/축소해서 최종 백버퍼(`_hdcBack`)에 합성한다.
기존 커스텀 UI(`UIManager`)는 바로 이 `_hdcGame`에 그대로 이어서 그려지고 있었다 — 즉
600px 폭 버퍼 밖으로는 물리적으로 그릴 수가 없는 구조였다. 오른쪽 300px 공간은 지금까지
ImGui 전용이었던 것.

## 해결: 패널 전용 논리 버퍼를 하나 더 만듦
게임 버퍼와 완전히 같은 패턴(고정 해상도로 그린 뒤 레터박스 합성)을 패널에도 그대로 적용했다.

- `GameInstance`에 `_hdcPanel`/`_bmpPanel` 추가 — `GImGuiPanelWidth x GWinSizeY`(300x800) 고정 버퍼
- `UpdateGameViewport()`가 게임 뷰포트(`_gameViewport`) 계산 직후, 그 오른쪽 남는 공간을
  `_panelViewport`로 계산 (역시 비율 유지 확대/축소)
- `GameInstance::Render()`: 게임 버퍼 합성 다음에 패널 버퍼를 채우고(`FillRect`로 짙은 회색 배경),
  `UIManager::Render(_hdcPanel)`을 호출해 UI를 그린 뒤, `_panelViewport` 자리에 블릿

## 좌표계 분리: UIBase에 "패널 공간" 개념 추가
기존 `UIBase::SetAnchor()`는 `EAnchor::RightTop` 등을 전부 전역 상수 `GWinSizeX/GWinSizeY` 기준으로
계산했다. 패널은 폭이 다르므로(300 vs 600), 같은 앵커 시스템을 재사용하려면 기준 폭을
인스턴스별로 바꿀 수 있어야 했다.

- `UIBase`에 정적 플래그 `s_activeSpaceIsPanel` + `SetActiveUISpace(bool)` 추가
- `SetAnchor()` 호출 시점에 그 값을 `_usePanelSpace` 멤버로 캡처해서 기억 (Update()는 한참 뒤에도
  계속 불리니까 매번 정적 상태를 다시 볼 수 없음)
- `_usePanelSpace`가 true면 앵커 기준 폭을 `GImGuiPanelWidth`로 사용
- `IsHoverInUI()`(마우스 히트 판정)도 `_usePanelSpace`에 따라 `GetPanelViewportRect()`/
  `GetPanelRectRatio()` vs `GetGameViewportRect()`/`GetRectRatio()`로 분기

`Widget_Main::Init()`/`Widget_Launch::Init()` 맨 앞에서 `UIBase::SetActiveUISpace(true)`를 켜고
끝에서 다시 꺼주는 식으로, 그 안에서 만들어지는 모든 자식 UI가 자동으로 패널 좌표계를 쓰게 했다.
개별 `AddChild<T>()->Init(...)` 호출부는 하나도 안 건드림.

## 삽질: 중복 렌더링 버그
1차 구현 후 실행해보니 UI가 오른쪽 패널이 아니라 여전히 게임 뷰포트 안(왼쪽 아래)에 나타났다.
원인은 `World::Render(hdc)` 안에 예전부터 있던 `UI.Render(hdc)` 호출 — `GameInstance::Render()`가
`WORLD.Render(_hdcGame)`을 부를 때 이 안에서 UI가 **또** `_hdcGame`에 그려지고 있었다.
`GameInstance::Render()`에 새로 추가한 `UIManager::Render(_hdcPanel)` 호출과 별개로 이게 계속
살아있었던 것 — 즉 같은 프레임에 UI가 두 번(게임 버퍼에 한 번, 패널 버퍼에 한 번) 그려지고 있었음.

해결: `World::Render()`의 `UI.Render(hdc)` 호출 제거. UI 렌더링은 이제 `GameInstance::Render()`가
패널 버퍼에 직접 그리는 것으로 일원화.

## 수정 파일
- `Core/GameInstance.h` / `.cpp` — 패널 버퍼, 뷰포트 계산, 렌더 경로
- `GameFramework/UIBase.h` / `.cpp` — 패널 좌표계 분기
- `GameFramework/World.cpp` — 중복 UI 렌더 호출 제거
- `Widget/Widget_Main.cpp`, `Widget/Widget_Launch.cpp` — Init() 앞뒤로 `SetActiveUISpace` 토글

## 검증
Debug/Release 둘 다 빌드 성공. Release exe를 직접 실행해서 스크린샷으로 확인 —
연료바/Refuel 버튼/헤딩 인디케이터가 게임 화면이 아니라 오른쪽의 새 회색 패널 안에
정상적으로 나타남 (Debug에서는 ImGui가 같은 자리를 덮어써서 육안으로는 안 보이지만,
렌더링 자체는 동일하게 동작 — Debug에서 ImGui를 잠깐 꺼보면 확인 가능).
